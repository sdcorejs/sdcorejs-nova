# C18 — Highlight / findHighlightRanges

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** components/highlight,utilities/extensions@c421f687. **Dùng cho:** Highlight search term trên text an toàn, hỗ trợ Vietnamese accent-insensitive matching.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type HighlightProps={text:string|number|null|undefined;term:string|null|undefined};
declare function findHighlightRanges(text:string,term:string):readonly {start:number;end:number}[];

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Highlight text={file.name} term={query} />
```

### State, interaction và rendering

Render text nodes + mark only, never dangerouslySetInnerHTML. Case/accent-insensitive including Đ/đ nhưng giữ original text exact grapheme boundaries; helper indexes UTF16 documented, returned ranges clamp nonoverlap. Whitespace-only term no mark, 0 text preserved. Long strings algorithm bounded linear candidate, no user regex eval. SR reads content naturally without repeated match announcements; mark contrast tokens/high contrast fallback. Pure no async, loading/error N/A; SSR deterministic.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; pure text helper, no Angular pipes/prototype changes. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C18-AC01: <img onerror> literal text, not DOM/image execution.
- C18-AC02: Nguyễn/NGUYEN and Đ/đ match while combining characters/emoji preserve original graphemes.
- C18-AC03: Empty term/null/0/overlap safe, large text no catastrophic regex, forced colors readable.
