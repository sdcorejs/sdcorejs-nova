# D06 — Kanban

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P3. **Nguồn Angular:** components/kanban@c421f687. **Dùng cho:** Board typed raw cards, move giữa cột bằng keyboard/menu/drag, consumer persistence.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type KanbanColumn={id:Key;label:string;disabled?:boolean};
type KanbanMove<T>={item:T;itemId:Key;fromColumn:Key;toColumn:Key;fromIndex:number;toIndex:number;previous:readonly T[];next:readonly T[];signal:AbortSignal};
type KanbanProps<T>={scopeKey:string;items:readonly T[];columns:readonly KanbanColumn[];getKey:(item:T)=>Key;getColumn:(item:T)=>Key;getTitle:(item:T)=>string;withColumn:(item:T,column:Key)=>T;onItemsChange:(items:readonly T[])=>void;onMove?:(request:KanbanMove<T>)=>Promise<boolean>;canMove?:(request:KanbanMove<T>)=>boolean;renderCard?:(item:T)=>ReactNode;filter?:(item:T)=>boolean;disabled?:boolean};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Kanban scopeKey={account.id} items={cards} columns={columns} getKey={c=>c.id} getColumn={c=>c.status} getTitle={c=>c.title} withColumn={(c,status)=>({...c,status})} onItemsChange={setCards} onMove={persistMove} />
```

### State, interaction và rendering

Existing c421 capability, absent older HEAD; not automatically source released just because merged. Controlled items only, withColumn returns new same-ID item; no mutation props. Async move proposes immutable snapshot, pending locks that move, only accept true emits onItemsChange; false/error keeps board with safe error. New props/scope/disabled/unmount abort and late approval ignored. Indexes refer full columns including filtered-out cards, destination index after source removed. Duplicate IDs/unknown column invalid visible diagnostic. Mobile horizontal columns or consumer list mode with menu move alternative, not drag-only; named Move to column / position controls. Live polite accepted move/reject, focus moved card when consumer confirms new data; no role grid unless keyboard contract explicitly supports. SSR no DnD globals. Singleflight **toàn board**, không chỉ một card: từ proposal tới async acceptance rồi chờ consumer props xác nhận ordered keys+columns của next, mọi move khác bị disabled. onItemsChange được gọi once sau accept; parent phải cập nhật immutable items. Authoritative props đổi khác next luôn thắng, unlock và invalidate pending proposal; parent không update sau callback thì giữ state Chờ cập nhật, dev diagnostic, không silently unlock để move trên stale snapshot. Không merge/rebase hai snapshot ngầm. Lỗi callback được catch safe error và giữ previous items.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; optional DnD adapter only if keyboard/touch proof, ActionMenu/DataState. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- D06-AC01: Drag/menu/keyboard same full-index move request raw T; filtered cards not reordered incorrectly.
- D06-AC02: Reject/throw no items callback; late accept after replacement/scope ignored.
- D06-AC03: CanMove false/disabled prevents request, number1/string1 distinct; keyboard move announcement+focus accessible.
- D06-AC04: Hai card move cùng lúc chỉ request đầu chạy; trong acceptance→parent confirmation cũng block move thứ hai; parent updates next hoặc authoritative replacement mới unlock, không lost update.
