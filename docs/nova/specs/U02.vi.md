# U02 — ImportWizard / workbook adapter

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/import-excel,services/excel. **Dùng cho:** Import bảng dữ liệu qua parse/map/validate/review, commit do consumer thực hiện.

**Non-goals:** Không xây ETL/backend import transaction; không tự chọn parser thương mại.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ImportColumn<T> = {[K in Extract<keyof T,string>]:{key:K;label:string;parse:(cell:unknown)=>T[K]}}[Extract<keyof T,string>];
type RowIssue={row:number;column?:string;severity:'error'|'warning';message:string};
type WorkbookAdapter={parse:(file:File,ctx:LoadContext)=>Promise<{sheets:readonly {name:string;rows:readonly (readonly unknown[])[]}[]}>};
type ImportWizardProps<T>={adapter:WorkbookAdapter;columns:readonly ImportColumn<T>[];validate:(rows:readonly T[],ctx:LoadContext)=>Promise<readonly RowIssue[]>;onCommit:(rows:readonly T[],ctx:LoadContext)=>Promise<{status:'success'}|{status:'rejected';issues:readonly RowIssue[]}>;maxRows:number;maxFileBytes:number};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<ImportWizard adapter={workbookAdapter} columns={columns} validate={validateContacts} onCommit={importContacts} maxRows={5000} maxFileBytes={5*1024*1024} />
```

### State, interaction và rendering

Không bundle Excel service mặc định. File limits bắt buộc consumer explicit; parse worker adapter preferred, sheet choose và header mapping, column parse preserve empty/0/false; warning confirm distinct blocking error. Row indexes display 1-based source row stable. Validated snapshot bound file/mapping/version; changed mapping invalidates commit. Core no Excel formulas eval, no macro, export formula cells strings escaped adapter, no remote fetch external workbook references. Submit singleflight; cancel parse/validate; commit cancel local does not rollback backend. Wizard dùng Stepper C08 với tên bước Chọn tệp / Ánh xạ cột / Kiểm tra / Xác nhận. Mapping select có label cột nguồn/đích; parse/validation tiến trình live polite không announce mỗi row. Khi user bấm Tiếp và lỗi, focus error summary có link tới mapping hoặc row/cell; automatic parse success không steal focus. Mobile review dùng labelled horizontal scroll table, footer actions còn reachable; keyboard đi tới row errors không chỉ tooltip. onCommit rejected issues dùng source row index giữ draft để sửa; success mới kết thúc wizard.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; optional workbook parser adapter with license audit; Dialog/Table/Field. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- U02-AC01: Header missing/duplicate prevents review, row limits/file compressed bomb adapter denies.
- U02-AC02: Invalid date/number rows show concrete cell issue, warnings allow explicit commit, error blocks.
- U02-AC03: Slow parse old file/old mapping result ignored; commit double click once, partial server rejection returns row errors keeps draft.
