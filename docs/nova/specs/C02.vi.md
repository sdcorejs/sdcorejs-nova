# C02 — ActionMenu / QuickActions

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** components/button,components/quick-action. **Dùng cho:** Menu consumer-owned cho từng item hoặc vùng toolbar.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ActionMenuProps<T> = { data: T; actions: readonly MenuAction<T>[]; label: string; disabled?: boolean; onActionError?: (error: unknown, actionId: string) => void };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<ActionMenu data={file} label="Thao tác tệp" actions={[{id:'rename',label:'Đổi tên',onAction: openRename}]} />
```

### State, interaction và rendering

Dữ liệu truyền nguyên T tới callback; hidden lọc khỏi menu, disabled còn visible nhưng không thực thi. Trigger Enter/Space/ArrowDown mở, arrows/Home/End/typeahead chuyển item, Escape đóng và trả focus. Child menu chỉ 1 cấp; click action async đánh dấu pending item, không block cả trang; lỗi gọi error callback và giữ menu phục hồi. Không tự CRUD. Nếu không visible actions, không render trigger rỗng. Overflow narrow menu có viewport clipping.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI phù hợp với primitive. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C02-AC01: Action nhận cùng raw object identity, không wrapper/string.
- C02-AC02: Nhóm sâu hơn 1 level bị type reject; runtime bad config hiện dev warning và không render nhóm sâu.
- C02-AC03: Tất cả hidden không có trigger; pending action click hai lần chỉ chạy một lần; rejection cho phép retry.
