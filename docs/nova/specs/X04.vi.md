# X04 — AuditDiff / HistoryTimeline

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P3. **Nguồn Angular:** components/audit-diff,components/history. **Dùng cho:** Hiển thị thay đổi và timeline với dữ liệu đã được consumer chuẩn bị.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type DiffEntry={path:readonly string[];before:unknown;after:unknown;kind:'add'|'remove'|'change'};
type AuditDiffProps={entries:readonly DiffEntry[];formatValue:(value:unknown,path:readonly string[])=>ReactNode};
type HistoryEntry<T>={id:string;timestamp:string;title:string;data:T};
type HistoryTimelineProps<T>={entries:readonly HistoryEntry<T>[];timeZone:string;renderDetail?:(data:T)=>ReactNode};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<AuditDiff entries={changes} formatValue={formatSafeValue} />
```

### State, interaction và rendering

Không core recursive diff mọi object/prototype; optional pure diff helper JSON-like data with cycle detection later review. Entries path separate no eval; value formatting mandatory avoids PII dumping. Semantic before/after labels, add/remove plus symbols/text not only red/green. Timeline timestamp ISO and explicit zone, no Date.now relative SSR. Empty no changes informative, async parent DataState. Expand detail button state local, action callbacks raw typed.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Section/ReadOnlyValue. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- X04-AC01: undefined/null/0/false preserve differences display; no auto JSON PII serialization.
- X04-AC02: Malicious path/__proto__ text never evaluated, cyclic raw value formatter consumer handles safe.
- X04-AC03: Timeline sorting consumer order stable, timezone SSR identical, no changes empty correct.
