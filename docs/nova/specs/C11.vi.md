# C11 — Dialog / Sheet / Drawer

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** components/modal,components/side-drawer. **Dùng cho:** Overlay có title, content, footer; Sheet side panel cho tác vụ phụ.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type DialogProps = ValueProps<boolean> & { title: ReactNode; description?: ReactNode; children: ReactNode; modal?: boolean; initialFocus?: React.RefObject<HTMLElement|null>; onCloseRequest?: (reason:'escape'|'outside'|'action') => void; returnFocus?: React.RefObject<HTMLElement|null>; closeDisabled?: boolean };
type SheetProps = DialogProps & { side?: 'start'|'end'|'bottom'; size?: 'sm'|'md'|'lg' };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Dialog value={open} onValueChange={setOpen} title="Đổi tên tệp"><RenameForm /></Dialog>
```

### State, interaction và rendering

Value boolean đại diện open. Modal trap focus, inert background, Escape/outside propose close; closeDisabled hiển thị lý do an toàn và explicit cancel khi có thể. Nested overlay Escape đóng top only; focus return trigger/fallback. Sheet narrow bottom/full-width theo CSS, không swipe-only đóng. Title obrigatório, scroll body/footer visible và safe-area. SSR theo G-RENDER portal mount, không global document side effects. initialFocus ref missing/nonfocusable falls back heading/first focusable, never body silently. Initial focus consumer initialFocus nếu focusable; default first relevant control, content dài dùng heading/container tabIndex=-1 để đọc đầu nội dung thay scroll tới footer. Description aria-describedby chỉ concise text; structured long content không gộp toàn bộ vào description. Nonmodal không inert/trap, mở không cướp focus mặc định trừ initialFocus explicit; Escape khi focus inside và return focus chỉ khi đóng bằng action của overlay.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Dialog/Drawer. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C11-AC01: Focus không thoát modal qua Tab/ShiftTab; Escape đề xuất close đúng once.
- C11-AC02: Nested menu Escape không đóng cả dialog; trigger removed dùng fallback focus.
- C11-AC03: Controlled false không portal content trước hydration; unmount clear body lock sau two dialogs.
