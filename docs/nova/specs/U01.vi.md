# U01 — FileUpload / useFileTransfer

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/upload-file. **Dùng cho:** Chọn/drop tệp, queue và progress bằng transfer adapter consumer.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type TransferState={id:string;direction:'upload'|'download';name:string;file?:File;status:'queued'|'running'|'success'|'error'|'cancelled';progress?:number;errorMessage?:string};
type TransferAdapter={upload:(file:File,ctx:{signal:AbortSignal;onProgress:(loaded:number,total?:number)=>void})=>Promise<{id:string}>;download?:(request:{id:string;name:string},ctx:{signal:AbortSignal;onProgress:(loaded:number,total?:number)=>void})=>Promise<Blob|void>};
type FileUploadProps={accept?:string;multiple?:boolean;maxFileBytes?:number;maxFiles?:number;disabled?:boolean;onFiles:(files:readonly File[])=>void;errors?:readonly string[]};
declare function useFileTransfer(options:{adapter:TransferAdapter;concurrency?:number}):{items:readonly TransferState[];enqueue:(files:readonly File[])=>void;cancel:(id:string)=>void;retry:(id:string)=>void;download:(request:{id:string;name:string})=>Promise<Blob|void>};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<FileUpload accept="image/*" maxFileBytes={10*1024*1024} onFiles={transfer.enqueue} />
```

### State, interaction và rendering

File picker native + drop region keyboard Button, max sizes consumer explicit; accept UX filter not security validation, server validates MIME/content/quota. Transfer default concurrency=2 recommendation, no retry automatically mutation. Cancel AbortSignal marks local cancelled, not promise remote delete; retry new attempt ID, backend idempotency consumer. progress undefined total indeterminate. Duplicate file same name allowed if bytes differ; key unique instance. Clear queue revokes previews; no File access at SSR. Download adapter opt-in, source id/name do consumer truyền; missing download adapter throws configuration error trước enqueue. TransferState direction distinguishes upload/download, name accessible và file chỉ có cho upload. Blob result returned consumer owns saving; void means browser handoff do adapter thực hiện sau user click, status text ghi Đã chuyển sang trình duyệt chứ không chứng minh tệp đã lưu ổ đĩa. Bytes total unknown indeterminate, download abort local ignores late completion; retry mutation/upload không tự động, read download retry explicit button. FileExplorer transfer panel composed hook, UI mặc định chỉ visible thao tác adapter đã cung cấp.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; browser File APIs; Progress/Button. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- U01-AC01: Exact max bytes accepted / max+1 rejected; zero byte allowed unless consumer denies.
- U01-AC02: Concurrency cap, cancel queued vs running, late success after cancel ignored.
- U01-AC03: Upload rejection safe message retry; unmount abort all and revoke URLs, keyboard drop alternate works.
- U01-AC04: Download Blob vs void handoff có status khác, missing adapter không giả success; caller URL không revoke, core-generated preview URL revoke once.
