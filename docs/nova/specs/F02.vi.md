# F02 — Input / Textarea

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** forms/input,forms/textarea. **Dùng cho:** Text/email/url/password fields và multiline user input.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type InputProps = ValueProps<string> & ControlProps & NativeInputProps & { type?:'text'|'email'|'url'|'password'|'search'|'tel'; placeholder?:string; autoComplete?:string; maxLength?:number };
type TextareaProps = ValueProps<string> & ControlProps & NativeTextareaProps & { rows?:number; maxLength?:number; resize?:'vertical'|'none' };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Input label="Email" type="email" autoComplete="email" value={email} onValueChange={setEmail} />
```

### State, interaction và rendering

Native input attrs và IME composition không transform phá gõ. Value string empty legitimate. Không trim/change case tự động. readOnly copyable, disabled không form submission theo native. Loading không built-in fetch; show trailing adornment via InputGroup. Textarea vertical resize/default rows=3, không đo scrollHeight SSR. Password toggle separate accessible button opt-in.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Input. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F02-AC01: IME tiếng Việt compose không emit normalized partial text khác native policy.
- F02-AC02: Controlled update giữ caret; empty/reset correct.
- F02-AC03: maxLength exact boundary and paste, 16px mobile no zoom; disabled không emit.
