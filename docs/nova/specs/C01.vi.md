# C01 — Button / IconButton

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** components/button. **Dùng cho:** CTA, hành động phụ và nút chỉ icon; ButtonGroup cho actions cùng vùng.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ButtonProps = { variant?: 'primary'|'secondary'|'ghost'|'danger'; size?: 'sm'|'md'|'lg'; loading?: boolean; disabled?: boolean; type?: 'button'|'submit'|'reset'; children: ReactNode; onClick?: React.MouseEventHandler<HTMLButtonElement> };
type IconButtonProps = Omit<ButtonProps,'children'> & { label: string; icon: ReactNode };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Button type="submit" loading={saving}>Lưu thay đổi</Button>
```

### State, interaction và rendering

Default type=button. Loading giữ width, aria-busy, ngăn click/submit lặp và có tên Lưu thay đổi, không đổi thành spinner-only. IconButton native button có aria-label. Mobile tăng hit area; content dài wrap. Không nhét menu items vào Button: dùng ActionMenu C02. Disabled không click; submit vẫn theo native form. SSR không tính icon random.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI phù hợp với primitive. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C01-AC01: Click enabled phát đúng một event; type mặc định không submit form.
- C01-AC02: Loading/disabled bấm chuột, Enter, Space không tạo request thứ hai.
- C01-AC03: Icon-only có name; label dài ở 320px không che sibling; ref trỏ button.
