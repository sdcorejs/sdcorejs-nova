# F07 — Select / Combobox / Autocomplete

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/select,forms/autocomplete. **Dùng cho:** Chọn key từ raw typed options; combobox tìm kiếm, autocomplete text suggestion.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type Option<T,K extends Key> = { key:K; label:string; data:T; disabled?:boolean };
type SelectProps<T,K extends Key> = ValueProps<K|null> & ControlProps & { options:readonly Option<T,K>[]; renderOption?:(data:T)=>ReactNode; loading?:boolean };
type ComboboxProps<T,K extends Key> = SelectProps<T,K> & { query?:string; onQueryChange?:(q:string)=>void };
type AutocompleteProps = ValueProps<string> & ControlProps & { suggestions:readonly string[] };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Select label="Quốc gia" value={countryId} onValueChange={setCountryId} options={countries.map(c=>({key:c.id,label:c.name,data:c}))} />
```

### State, interaction và rendering

Key state independent raw T, no broad any/object identity key. Select listbox keyboard arrows/typeahead/Enter/Escape, combobox editable query with aria-activedescendant; loading options has status, empty distinct from error passed Field. Clear null. Stale selected key visible unresolved label fallback consumer resolution, no silent removal. Autocomplete free text does not force suggestion key. Narrow popup fits viewport; SSR options stable.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Select/Combobox/Autocomplete. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F07-AC01: Select raw renderer T, duplicate keys invalid diagnostic.
- F07-AC02: Out-of-order external query results consumer latest-wins; typing IME no premature select.
- F07-AC03: Key 0, hidden disabled option, no-results and Escape preserve prior selection.
