# C07 — Tabs / TabPanel

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** components/tab. **Dùng cho:** Chuyển vùng nội dung trong cùng trang.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type TabsProps = ValueProps<string> & { activation?: 'automatic'|'manual'; orientation?: 'horizontal'|'vertical'; children: ReactNode };
type TabProps = { value: string; disabled?: boolean; children: ReactNode };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Tabs defaultValue="overview"><TabList><Tab value="overview">Tổng quan</Tab><Tab value="activity">Hoạt động</Tab></TabList><TabPanel value="overview">...</TabPanel><TabPanel value="activity">...</TabPanel></Tabs>
```

### State, interaction và rendering

Arrow/Home/End roving focus; manual dùng Enter/Space activate; panel link aria-controls/labelledby. Disabled skipped. Content mount-on-demand mặc định; keepMounted explicit cho form state, hidden inert panel không focusable. Narrow scroll tablist có affordance; không router state hoặc persistence ngầm. value thiếu tab hiển thị fallback có warning, không emit trong render.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Tabs. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C07-AC01: Controlled click chỉ callback, panel chờ prop mới.
- C07-AC02: Manual ArrowRight không đổi panel trước Enter; disabled skipped.
- C07-AC03: Unmount panel cleanup request, keepMounted không có tab stops ẩn; RTL arrows test.
