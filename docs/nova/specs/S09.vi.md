# S09 — useStoredState / PersistenceAdapter

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** services/storage,services/persistence. **Dùng cho:** Opt-in persistence cho UI preferences không nhạy cảm với schema version.

**Non-goals:** Không port cyclic graph serializer, auth/session storage hoặc backup database.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type StorageAdapter={read:(key:string)=>Promise<string|null>;write:(key:string,value:string)=>Promise<void>;remove:(key:string)=>Promise<void>};
declare function useStoredState<T>(options:{key:string;scopeKey:string;version:number;initial:T;adapter:StorageAdapter;encode:(value:T)=>string;decode:(value:string)=>T;migrate?:(oldPayload:string,oldVersion:number)=>T}):{value:T;setValue:(value:T)=>void;status:'loading'|'ready'|'error';reset:()=>Promise<void>};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
const pref=useStoredState({key:'table.columns',scopeKey:account.id,version:1,initial:[],adapter,encode:JSON.stringify,decode:parseColumnIds});
```

### State, interaction và rendering

Không general graph serializer/prototype restoration; only caller codec/version schema. SSR initial deterministic, client read effect then apply; no localStorage module reference. Scope must include tenant/user via app supplied nonsecret namespace, clear user prefs on logout consumer. Writes serialized latest desired state, no automatic conflict merges across tabs; explicit revision adapter extension. Quota/corrupt/version error safe fallback initial+status error, not silent data loss success. Không tokens/PII/session credential persistence. Storage bytes là JSON envelope {version:number,payload:string}; codec encode/decode chỉ payload. Version mới hơn không migrate backward tự động. setValue trước initial read đánh dấu local revision và thắng read cũ; read response chỉ apply khi revision unchanged. reset increments generation, abort/ignore read, cancel writes chưa started, chờ writes started settle rồi remove serialized cuối; callback cũ không tái ghi sau reset. scope/key generation isolate mọi read/write completion.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; explicit adapter browser-only localStorage factory. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S09-AC01: Corrupt JSON/version mismatch fallback/error, migrate success schema validated.
- S09-AC02: Key/scope swap late read ignored, writes old scope not new.
- S09-AC03: Quota reject status error, reset remove catches error; two instances no module cache shared.
- S09-AC04: setValue trước read resolve không bị overwrite; reset giữa queued write/late read không tái tạo key; envelope old version migrate nhận oldVersion thật.
