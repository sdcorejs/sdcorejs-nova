# F12 — InlineEdit

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/inline-text. **Dùng cho:** Đổi từ text face sang edit control trên click/keyboard.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type InlineEditProps<T> = { value:T; display:ReactNode; renderEditor:(args:{draft:T;setDraft:(v:T)=>void;error?:string})=>ReactNode; onSave:(value:T,ctx:LoadContext)=>Promise<void>; disabled?:boolean; label:string };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<InlineEdit value={name} display={name} label="Tên hiển thị" renderEditor={({draft,setDraft})=><Input aria-label="Tên hiển thị" value={draft} onValueChange={setDraft}/>} onSave={saveName} />
```

### State, interaction và rendering

Display native button named Chỉnh sửa <label>, Enter enters focused editor; explicit Save/Cancel. Escape cancel draft, multiline Enter không save; save pending singleflight, errors keep editor/draft. Success doesn't optimistic mutate prop; consumer updates value, then closes on resolve. Scope/value remote change during edit shows conflict and blocks overwrite until consumer resolution; AbortSignal cleanup no remote rollback claim.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Button/Input/Field. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F12-AC01: Cancel restores old value and focus face; disabled no entry.
- F12-AC02: Failed save preserves draft; double Save one request.
- F12-AC03: Prop changes during dirty draft flags conflict; unmount abort and no late focus.
