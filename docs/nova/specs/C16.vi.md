# C16 — AnchorNavigation / AnchorSection

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** components/anchor. **Dùng cho:** Mục lục và điều hướng section trong trang, có scroll spy và active anchor.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type AnchorItem={id:string;title:string};
type AnchorNavigationProps={items:readonly AnchorItem[];label?:string;activeId?:string;onActiveIdChange?:(id:string)=>void;scrollRoot?:React.RefObject<HTMLElement|null>;offsetPx?:number};
type AnchorSectionProps={id:string;title:ReactNode;headingLevel?:2|3|4;children:ReactNode};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<><AnchorNavigation items={[{id:'billing',title:'Thanh toán'}]} /><AnchorSection id="billing" title="Thanh toán">...</AnchorSection></>
```

### State, interaction và rendering

Capability Angular anchor là TOC/scroll spy, không phải anchored popup C12. Navigation dùng anchor href #id chuẩn, click scroll và focus heading tabIndex=-1; active aria-current=location. IntersectionObserver chỉ sau mount, unregister khi sections thay đổi/unmount; fallback browser hash navigation nếu không support. Reduced motion instant scroll; offset token cho sticky header. Mobile mục lục collapsible sheet hoặc inline list, không hide toàn bộ navigation context. Scroll spy active local nếu activeId omitted, controlled chỉ callback; chỉ click mới update URL hash nếu consumer opt-in, scrolling không spam history. Missing section id giữ link và diagnostic, duplicate IDs rejected.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; IntersectionObserver/native hash links. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C16-AC01: Click anchor keyboard đưa focus heading và không nằm dưới sticky header.
- C16-AC02: Scroll đổi active id, controlled chờ prop; unmount/section removal disconnect observer.
- C16-AC03: SSR dùng stable IDs/href, reduced motion không smooth scroll; narrow TOC còn keyboard path.
