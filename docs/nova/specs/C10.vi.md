# C10 — DataState / Empty / Skeleton / Spinner / Progress

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** components/data-state,components/job-progress,utilities/data-state,utilities/read-state. **Dùng cho:** Diễn tả initial load, refresh, empty, failure và progress chuẩn.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type DataStateProps = { state: 'idle'|'loading'|'empty'|'error'|'ready'; message?: string; onRetry?: () => void; children?: ReactNode; refreshing?: boolean };
type ProgressProps = { value?: number; max?: number; label: string };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<DataState state={failed?'error':items.length?'ready':'empty'} onRetry={reload}>{list}</DataState>
```

### State, interaction và rendering

State explicit, không infer empty bằng falsy. Initial loading aria-busy region; refreshing giữ children + status. Error safe message và retry only if callback. Progress undefined indeterminate; finite clamp 0..max, max>0, no NaN DOM. Skeleton aria-hidden; Spinner role status có text. Empty có title/action consumer, disabled retry khi request pending.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Progress. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C10-AC01: 0/false data không inferred empty.
- C10-AC02: Refresh giữ rows/focus; initial load có status và no fake empty.
- C10-AC03: Progress NaN/negative/over max xử lý deterministic; empty retry N/A; error có callback clickable một lần.
