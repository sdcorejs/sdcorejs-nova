# X05 — SchemaFormRenderer (optional)

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P3. **Nguồn Angular:** components/form-generic. **Dùng cho:** Render form qua discriminated field schema khi app có nhu cầu cấu hình runtime.

**Non-goals:** Không port FormBuilder drag/drop/schema persistence của Angular như business-free requirement.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type FieldSchema<T> = {[K in Extract<keyof T,string>]:{key:K;label:string;required?:boolean} & (NonNullable<T[K]> extends number ? {kind:'number'}|{kind:'select';options:readonly {value:T[K];label:string}[]} : NonNullable<T[K]> extends boolean ? {kind:'boolean'} : NonNullable<T[K]> extends string ? {kind:'text'}|{kind:'date';validateISODate:(value:T[K])=>boolean}|{kind:'select';options:readonly {value:T[K];label:string}[]} : {kind:'custom';render:(value:T[K])=>ReactNode})}[Extract<keyof T,string>];
type SchemaFormProps<T>={schema:readonly FieldSchema<T>[];values:T;onValuesChange:(values:T)=>void;renderCustom?:(field:FieldSchema<T>,values:T)=>ReactNode;errors?:readonly ValidationIssue<Extract<keyof T,string>>[]};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<SchemaForm schema={profileFields} values={profile} onValuesChange={setProfile} errors={issues} />
```

### State, interaction và rendering

Renderer only, not drag/drop FormBuilder, remote executable expressions or Angular component registry. Schema field kind maps compatible value type via compile generic refinement required in implementation; nested child group one level initially if needed explicit future contract, not arbitrary recursion. No hidden validation/save fetch. Unknown kind safe unsupported message, do not silently text fallback. Consumer defaults explicit, preserves unknown fields in values. Mobile consistent Field stack. date kind string phải validateISODate runtime, không TypeScript branded ISO bảo đảm string calendar hợp lệ; select options value T[K] typed. Các field object/array dùng custom render, không silently text.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Field+control set; optional form adapter. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- X05-AC01: Unknown schema kind runtime clear unsupported, no eval JS/function string.
- X05-AC02: Field type mismatch TS negative fixture, required validation shared but renderer no second engine.
- X05-AC03: Reorder schema keeps draft by key, duplicate key invalid; empty schema renders no invented Save.
