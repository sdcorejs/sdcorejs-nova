# C17 — CollapsibleSection / Accordion

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** components/section. **Dùng cho:** Mở/đóng vùng nội dung dài có heading và action riêng.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type CollapsibleSectionProps=ValueProps<boolean>&{title:ReactNode;headingLevel?:2|3|4;children:ReactNode;actions?:ReactNode;disabled?:boolean;keepMounted?:boolean};
type AccordionProps=ValueProps<readonly string[]>&{multiple?:boolean;children:ReactNode};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<CollapsibleSection defaultValue={false} title="Thông tin bổ sung">...</CollapsibleSection>
```

### State, interaction và rendering

Value boolean nghĩa expanded; Accordion collection item IDs stable, single/multiple mode explicit. Heading chứa một button aria-expanded/controls, actions là sibling, click action không toggle vùng. Enter/Space native button, arrows optional accordion header focus theo upstream. Collapsed unmount default; keepMounted hidden/inert, no focusable descendants. Nếu collapse khi focus trong panel, focus về heading trước hiding; disabled không toggle. useId SSR, không module counter Angular. Mobile full width và không hit area nhỏ. Loading/error consumer DataState bên trong, không confuse collapsed=empty.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Collapsible/Accordion. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C17-AC01: Header click/Enter toggle once, sibling action không toggle.
- C17-AC02: KeepMounted hidden descendants không tab; collapse active focus returns header.
- C17-AC03: Accordion single mode không hai open; reordered item giữ keys; nested header IDs SSR unique.
