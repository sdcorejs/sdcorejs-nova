# S01 — NovaProvider / ThemeProvider / useNovaTheme

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** configurations,modules/icon,i18n. **Dùng cho:** Theme, locale/dir và defaults presentation theo root instance.

**Non-goals:** Không mimic Angular DI/provider-for-every-service.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type NovaProviderProps={children:ReactNode;locale?:'vi'|'en'|string;timeZone?:string;dir?:'ltr'|'rtl';theme?:'light'|'dark'|'system';initialResolvedTheme?:'light'|'dark';strings?:Partial<NovaStrings>;portalContainer?:HTMLElement|null};
declare function useNovaTheme():{theme:'light'|'dark'|'system';resolvedTheme:'light'|'dark'};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<NovaProvider locale="vi" theme="light"><App /></NovaProvider>
```

### State, interaction và rendering

No global service registry. Theme state app-owned; system reads matchMedia effect after mount, first server/client initialResolvedTheme default light. CSS prefers-color-scheme may style system before effect without changing markup. Provider portal context supplies theme; nested roots override not cross-contaminate. Icon default caller ReactNode/SVG, no mandatory Material icon font. Strings catalog typed per component. Provider locale change recalculates display no reset field values. timeZone provider mặc định UTC, invalid IANA zone tạo config diagnostic và fallback UTC; hook option overrides. Strings actual catalog là namespaces dialogs/forms/calendar/table/feedback/files/task/navigation; NovaStrings đoạn S02 chỉ minh họa common, catalog export hoàn chỉnh phải typecheck missing keys ở implementation gate.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI direction primitives. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S01-AC01: Two roots dark/vi vs light/en do not share state/toasts/theme.
- S01-AC02: Server import no window, hydration identical with system; listener cleaned.
- S01-AC03: Portal inside dark root retains tokens/dir; missing translation fallback en+dev diagnostic.
