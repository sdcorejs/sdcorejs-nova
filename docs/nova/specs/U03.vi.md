# U03 — ImagePreview / PdfPreview

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/preview. **Dùng cho:** Xem ảnh/PDF user-selected, download/print actions consumer-owned.

**Non-goals:** Không tự tải URL có credential, không guarantee PDF content accessible nếu adapter thiếu text layer.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ImagePreviewProps={src:string;alt:string;onError?:()=>void;onDownload?:()=>void};
type PdfAdapter={open:(source:Blob|string,ctx:LoadContext)=>Promise<{pageCount:number;renderPage:(page:number,target:{canvas:HTMLCanvasElement;textLayer:HTMLElement},ctx:LoadContext)=>Promise<void>;accessibleTextLayer:true;dispose:()=>void}>};
type PdfPreviewProps={source:Blob|string;adapter:PdfAdapter;title:string;onDownload?:()=>void;onPrint?:()=>void};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<PdfPreview source={blob} adapter={pdfAdapter} title="Hóa đơn" onDownload={downloadInvoice} />
```

### State, interaction và rendering

PDF engine lazy client, worker URL/CSP app explicit, không engine globals import SSR. Page navigation labels n/N, zoom bounded recommendation 25..400%, text layer/accessibility adapter bắt buộc cho document content không chỉ canvas. Error corrupted/password/unsupported distinct safe message. Image alt, contain/zoom keyboard + reset, narrow fit. URL allowlist host/auth consumer; không fetch arbitrary src through server proxy. Cancel render prior page/source; cleanup document+worker+URLs only core-owned URLs. Print callback no silent window print. Adapter renderPage nhận cả canvas+textLayer, render selectable text đúng reading order cùng page; canvas aria-hidden khi textLayer accessible. accessibleTextLayer phải true và có nội dung/text-alternative cho scanned PDF, nếu adapter thiếu/cannot extract thì UI báo tài liệu không có text accessible và hiển thị consumer alternate document/download action; không claim content WCAG pass cho scanned PDF. Source/page dispose xóa textLayer listeners và cancels page render. Document title/page selector accessible names tách khỏi document content.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; optional PDF.js adapter reviewed licensing/worker; Dialog/Button. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- U03-AC01: Invalid/corrupt PDF shows retry/action safe, empty pageCount invalid handled.
- U03-AC02: Page 1/N boundaries, source swap cancels render, unmount dispose once.
- U03-AC03: Image load failure fallback, zoom keyboard và fit mobile; PDF text layer SR verified adapter.
- U03-AC04: Adapter thiếu capability text layer bị chặn preview canvas-only, fallback accessible và scan không text có thông báo; normal PDF SR reading order và text selection chuẩn.
