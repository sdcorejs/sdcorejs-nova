# F13 — TreeSelect / EntityPicker

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** forms/tree-select,forms/entity-picker. **Dùng cho:** Chọn key từ hierarchy hoặc paged entity catalog lớn.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type EntityPickerProps<T,K extends Key> = ValueProps<readonly K[]> & ControlProps & { scopeKey:string;getKey:(item:T)=>K;getLabel:(item:T)=>string;load:(request:{query:string;pageIndex:number;pageSize:number;signal:AbortSignal})=>Promise<{items:readonly T[];total:number}>;hydrate?:(keys:readonly K[],ctx:LoadContext)=>Promise<readonly T[]>;multiple?:boolean };
type TreeSelectProps<T,K extends Key> = ValueProps<readonly K[]> & ControlProps & { scopeKey:string;tree:TreeSource<T,K>;getKey:(item:T)=>K;getLabel:(item:T)=>string };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<EntityPicker label="Người nhận" scopeKey={account.id} value={recipientIds} onValueChange={setRecipientIds} getKey={u=>u.id} getLabel={u=>u.name} load={searchUsers} hydrate={resolveUsers} />
```

### State, interaction và rendering

Modal picker draft selection, Apply commits, Cancel preserves value. Cross-page keys retained, hydrate selected keys not current page; missing entity shows unresolved key + retry, never drops. load latest-wins query/page and AbortSignal; reset page query changes; total contract nonnegative. TreeSelect no cascade by default; loaded descendants cascade opt-in không select unknown future children. Mobile sheet and accessible selected summary.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Dialog/Tree/Table/Combobox. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F13-AC01: Select page1+page2 apply all keys; cancel no callback.
- F13-AC02: Query A slow/B fast shows B only; scope change abort hydrate and load.
- F13-AC03: Missing key retained, zero results vs error separated; single mode max1; duplicate keys reject.
