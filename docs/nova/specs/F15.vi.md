# F15 — InlineText

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/inline-text. **Dùng cho:** Text input gọn theo độ dài cho inline/chips, không ép Save workflow.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type InlineTextProps=ValueProps<string>&ControlProps&{minChars?:number;chrome?:'standalone'|'seamless';clearable?:boolean;onEnter?:()=>void;onEscape?:()=>void};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<InlineText label="Từ khóa" value={keyword} onValueChange={setKeyword} onEnter={apply} />
```

### State, interaction và rendering

Ánh xạ đúng sd-inline-text: primitive borderless content-hugging input với raw value, consumer quyết định parse/commit. minChars default2/max visual width via CSS, not limit business text; size attr deterministic, no hidden measurement DOM. Enter composition không gọi onEnter, Escape callback không tự revert; clear emits '' once và retains focus. Seamless dùng host focus ring nhưng luôn cần visible ring ownership; standalone own ring. F12 InlineEdit là composition mới riêng, không tuyên bố existing Angular save service.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; native input/Field. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F15-AC01: IME Enter no premature commit; clear once empty string và focus retained.
- F15-AC02: Value dài wrap/scroll nội bộ không overflow 320px; minChars0 invalid clamp2 diagnostic.
- F15-AC03: Uncontrolled defaultValue initializes once, controlled preserves caret; seamless keyboard focus visible.
