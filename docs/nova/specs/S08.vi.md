# S08 — useViewport / useMediaQuery

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** services/viewport,directives,modules/layout. **Dùng cho:** JS viewport logic khi CSS không đủ, initial SSR snapshot explicit.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
declare function useMediaQuery(query:string,options?:{serverMatch?:boolean}):boolean;
declare function useViewport(options?:{serverWidth?:number}):{width:number|undefined;height:number|undefined};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
const reduceMotion=useMediaQuery('(prefers-reduced-motion: reduce)',{serverMatch:true});
```

### State, interaction và rendering

Presentation ưu tiên CSS, hook không render hai cây desktop/mobile làm mismatch. useSyncExternalStore server snapshot same first client, subscribe after hydrate; serverWidth undefined default. Throttle resize frame, listener shared per mounted provider optional no global leak; no user-agent sniffing. Hidden content nếu CSS still semantic hide correct.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; browser matchMedia/Resize APIs. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S08-AC01: ServerMatch true first hydration same even client false, updates after mount.
- S08-AC02: Unmount removes resize/matchMedia listeners and RAF.
- S08-AC03: Width0/undefined valid, iframe root independent, narrow no focus loss from JS hidden branch.
