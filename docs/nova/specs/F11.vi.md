# F11 — CalendarChips

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** forms/chip-calendar. **Dùng cho:** Chọn tập ngày rời rạc dưới dạng chips.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type CalendarChipsProps = ValueProps<readonly ISODate[]> & ControlProps & { min?:ISODate;max?:ISODate;maxDates?:number };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<CalendarChips label="Ngày nghỉ" value={days} onValueChange={setDays} />
```

### State, interaction và rendering

Combine F08 chips + F09 calendar; deduplicate dates, ascending output canonical, consumer decides business holidays. Multi date toggles selection; maxDates reached disabled unselected days with explanation. Remove chip returns focus stable. Read-only render formatted dates, empty placeholder. Date-only SSR invariance.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Calendar/ChipInput. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F11-AC01: Same date added twice no duplicate callback content.
- F11-AC02: Selected day can remove at max; impossible date rejects.
- F11-AC03: Calendar keyboard selected states and chip remove names full localized date.
