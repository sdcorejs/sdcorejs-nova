# F05 — Checkbox / Switch

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** forms/checkbox,forms/switch. **Dùng cho:** Boolean hoặc tri-state checkbox, immediate boolean setting switch.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type CheckboxProps = ValueProps<boolean|'mixed'> & ControlProps;
type SwitchProps = ValueProps<boolean> & ControlProps;

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Checkbox label="Chấp nhận điều khoản" value={accepted} onValueChange={v=>setAccepted(v===true)} />
```

### State, interaction và rendering

Checkbox mixed aria-checked=mixed, user activate → true; Switch chỉ boolean, không mixed. Space toggles, click label đúng một lần. readOnly prevents value change nhưng focusable; disabled native semantics. Loading save policy consumer may disabled but error must restore displayed previous truth explicitly. Visual compact retains 44px hit target.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Checkbox/Switch. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F05-AC01: Mixed→true callback once; controlled false không toggle DOM until prop.
- F05-AC02: Disabled Space/click no emit; Switch mixed TS error.
- F05-AC03: Standalone label hoặc aria-label có name, no naming contract bị TS reject; nameFromField chỉ hợp lệ trong FieldRoot, mixed checkbox SR và disabled contrast visible.
