# D05 — FileExplorer (existing base + Nova adaptations)

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/file-explorer@c421f687; release-source v2.15. **Dùng cho:** Điều hướng thư mục và hiển thị tệp cho end user, composed tree/list, consumer owns actions.

**Non-goals:** Không nhập các quyết định Explorer draft của nhiệm vụ khác thành mặc định chưa review.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ExplorerItem<T>={key:Key;name:string;kind:'file'|'folder';data:T;hasChildren?:boolean};
type FileExplorerProps<T>={scopeKey:string;view?:'list'|'grid';onViewChange?:(view:'list'|'grid')=>void;search?:(request:{folderKey:Key|null;query:string;signal:AbortSignal})=>Promise<readonly ExplorerItem<T>[]>;columns?:readonly Column<T>[];renderGridItem?:(data:T)=>ReactNode;onOpen?:(data:T)=>void;roots:readonly ExplorerItem<T>[];folderKey:Key|null;onFolderChange:(key:Key|null)=>void;loadChildren:(folder:ExplorerItem<T>|null,ctx:LoadContext)=>Promise<readonly ExplorerItem<T>[]>;actions?:readonly MenuAction<T>[];selectedKeys?:readonly Key[];onSelectedKeysChange?:(keys:readonly Key[])=>void;renderPreview?:(item:T)=>ReactNode};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<FileExplorer scopeKey={account.id} roots={roots} folderKey={folder} onFolderChange={setFolder} loadChildren={readFolder} actions={actions} selectedKeys={selected} onSelectedKeysChange={setSelected} />
```

### State, interaction và rendering

Base FileExplorer có ở reference snapshot c421f687 và release-associated tag/archive v2.15, không có tại selected working HEAD4db0ac9. Không tự upload/delete/rename/download/auth/backends, raw data action T; only one child level loader. Breadcrumb+folder nav+table/list; narrow folder chooser sheet and content list, no desktop split squeeze. Folder navigation latest-wins, per folder loading/error/empty/retry. Consumer selection across folders policy explicit mặc định clear via consumer onFolderChange orchestration, component does not secretly mutate controlled keys. Preview optional lazy; file upload composed U01 outside. Base Angular list/search/list-grid/open/preview/transfer/share/create-folder được phân bổ: list/search/view/open ở D05; preview U03; upload/download U01; share/createFolder/rename/delete qua consumer ActionMenu và form Dialog, không tích hợp API backend. Nova consumer-owned actions 1 level, typed data T, selector/columns là adaptation proposal có rationale reuse D01, không mô tả draft enhancements task khác đã released. selectedKeys+callback opt-in phải xuất hiện cùng nhau, default không selection; custom columns/renderGridItem optional, default metadata name/kind và producer renders raw T. view omitted local list/grid state default list, controlled view cần callback. Search không callback dùng local current-folder name filter accent-insensitive C18, callback search remote latest-wins không cache query cũ. Scope đổi resets preview/search/cache, abort all read; Folder navigation abort unlike Angular base caches navigating-away reads — intentional simpler request-isolation default. onOpen fires once user file open, never folder or rerender. Grid là CSS list/card layout với semantic list, không role=grid khi chưa có spreadsheet keyboard contract. Đổi list/grid giữ focused key và logical action; search làm item mất thì focus search input/nearest visible item theo user action, fetch completion không tự steal focus.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Tree/DataTable/Breadcrumb/DataState/Sheet. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- D05-AC01: Folder A→B late A never displayed B; abort on unmount.
- D05-AC02: Action gets raw T, no default delete menu, no deep child recursion.
- D05-AC03: Empty folder khác leaf file; inaccessible folder error không suggest empty; touch and keyboard back/breadcrumb parity.
- D05-AC04: List/grid giữ same keys và callback onOpen raw T once; absent selection props no selector, paired mismatch diagnostic; remote search late query ignored.
