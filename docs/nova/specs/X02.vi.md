# X02 — CodeEditor

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P3. **Nguồn Angular:** components/code-editor. **Dùng cho:** Code text editing qua lazy adapter cho app có nhu cầu end user technical.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type CodeEditorProps = ValueProps<string> & ControlProps & {language:string;adapter:{render:(props:{value:string;onChange:(value:string)=>void;language:string;readOnly:boolean;disabled:boolean;accessible:ResolvedAccessibleName})=>ReactNode};height?:number};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<CodeEditor label="Cấu hình JSON" language="json" value={config} onValueChange={setConfig} adapter={monacoAdapter} />
```

### State, interaction và rendering

Fallback textarea SSR, mounted lazy editor preserves value. Không eval/run code; diagnostics adapter passes safe messages, language worker CSP app-configured. Tab indent là editor mode explicit; Escape/shortcut lets keyboard exit (không trap). Theme adapter receives token scheme, plain text accessible mirror/name. ReadOnly copy, disabled no edits. No app loading/save responsibility. Adapter nhận disabled và resolved accessible attributes từ Field, không ép ReactNode label thành string; disabled editor suppresses every mutation callback và updates host semantics.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; optional Monaco/CodeMirror adapter licensing at adoption. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- X02-AC01: Malicious JS input never executes; worker configured CSP no unsafe-eval assumption.
- X02-AC02: Keyboard Tab escape documented and operable, IME preserved.
- X02-AC03: Late adapter load after unmount ignored; source change editor value sync, no duplicate instance.
