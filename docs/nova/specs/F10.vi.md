# F10 — TimeInput / TimeRangeInput / DateTimePicker

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/time,forms/time-range,forms/datetime. **Dùng cho:** Giờ local và instant datetime trong explicit timezone.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type LocalTime = string; // HH:mm hoặc HH:mm:ss
type TimeInputProps = ValueProps<LocalTime|null> & ControlProps & { precision?:'minute'|'second';min?:LocalTime;max?:LocalTime };
type TimeRangeInputProps = ValueProps<{start:LocalTime|null;end:LocalTime|null}> & ControlProps & { allowOvernight?:boolean };
type DateTimePickerProps = ValueProps<string|null> & ControlProps & { timeZone:string; disambiguation?:'reject'|'earlier'|'later' };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<DateTimePicker label="Thời điểm bắt đầu" timeZone="Asia/Ho_Chi_Minh" value={startInstant} onValueChange={setStartInstant} />
```

### State, interaction và rendering

LocalTime không Date epoch. DateTime emits ISO instant UTC Z và displays explicit zone. DST ambiguous/nonexistent default reject; earlier/later opt-in only ambiguous overlap, nonexistent cần resolution message. Không đổi timezone dựa server/browser. TimeRange overnight mặc định false; true hiển thị hôm sau. Keyboard segment/native text, mobile numeric keyboard; no spinner-only complex widget requirement.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; explicit timezone adapter candidate, native Intl. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F10-AC01: 23:59/00:00 valid, 24:00 rejected, seconds precision exact.
- F10-AC02: New York DST gap/overlap reject default, explicit earlier/later produce different instants.
- F10-AC03: Overnight forbidden vs allowed and same start=end interpreted zero duration; zone change keeps instant.
