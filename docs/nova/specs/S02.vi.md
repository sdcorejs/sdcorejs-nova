# S02 — useFormatter / i18n strings

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** i18n,pipes. **Dùng cho:** Date/number/time formatting pure Intl and localized UI strings.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
declare function useFormatter(options?:{timeZone?:string}):{number:(value:number,opts?:Intl.NumberFormatOptions)=>string;date:(value:ISODate)=>string;instant:(value:string,opts?:Intl.DateTimeFormatOptions)=>string};
type NovaCommonStrings={close:string;loading:string;empty:string;retry:string;removeItem:(label:string)=>string;selectedCount:(count:number)=>string};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
const fmt=useFormatter({timeZone:'Asia/Ho_Chi_Minh'});
<ReadOnlyValue value={total} display={fmt.number(total)} />
```

### State, interaction và rendering

Unknown number NaN returns localized unavailable, not NaN accidental UI; invalid temporal yields safe unavailable. Date-only formatter uses civil components, not shift timezone; instant explicit zone default provider configured UTC recommendation. RelativeTime optional pure function takes now explicit to avoid SSR ticking; client timer opt-in cleans. SafeHtml pipe no port; ReactNode is preferred and sanitized editor adapter exception. Empty pipe maps isEmptyValue only null/undefined/empty string, not 0/false.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; native Intl. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S02-AC01: vi/en decimal/plural 0/1/many right and no key leaks.
- S02-AC02: Date-only timezone invariant, invalid date safe, DST instant explicit zone.
- S02-AC03: Relative now SSR snapshot same client, timer cleanup opt-in; safeHtml not exported.
