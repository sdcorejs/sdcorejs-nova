# X01 — RichTextEditor / MiniEditor

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P3. **Nguồn Angular:** components/editor,components/mini-editor,components/ckeditor-styles. **Dùng cho:** Editor nội dung cơ bản hoặc rich text qua adapter optional.

**Non-goals:** Không chọn CKEditor premium, collaboration hay document storage trong Core.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type EditorDocument = {format:'html'|'markdown';content:string};
type EditorAdapter = { render:(args:{value:EditorDocument;onChange:(value:EditorDocument)=>void;disabled:boolean;readOnly:boolean;accessible:ResolvedAccessibleName})=>ReactNode };
type RichTextEditorProps = ValueProps<EditorDocument> & ControlProps & {adapter:EditorAdapter;sanitize:(html:string)=>string};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<RichTextEditor label="Nội dung" value={body} onValueChange={setBody} adapter={editorAdapter} sanitize={sanitizeHtml} />
```

### State, interaction và rendering

Không copy CKEditor styling/package quyền từ Angular. MiniEditor simple subset bold/italic/link/lists, toolbar roving focus and formatting pressed state. Sanitize display HTML và app persisted render trust boundary, core does not bypass sanitizer. Upload image uses explicit consumer callback adapter AbortSignal, no upload endpoint. ReadOnly semantic rendered content with sanitized HTML, disabled no editing. Lazy engine client placeholder SSR same first render. Paste untrusted stripped, links safe protocols. AccessibleName resolved thành {id,ariaLabel?,ariaLabelledby?,ariaDescribedby?}; adapter áp tới actual editing root; không string-coerce ReactNode label.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; optional editor adapter license owner verifies, Field/Button. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- X01-AC01: Paste script/event handlers removed by required sanitizer fixture.
- X01-AC02: IME undo/redo and toolbar keyboard, readOnly không emit.
- X01-AC03: Unmount upload/editor dispose, heavy engine absent Button bundle; HTML empty vs paragraph-only normalized adapter contract.
