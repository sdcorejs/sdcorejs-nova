# X03 — OrgChart

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P3. **Nguồn Angular:** components/org-chart. **Dùng cho:** Sơ đồ hierarchy tổng quát cho end user, không domain HR built-in.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type OrgChartProps<T>={roots:readonly T[];getKey:(item:T)=>Key;getChildren:(item:T)=>readonly T[];getLabel:(item:T)=>string;renderNode?:(item:T)=>ReactNode;onSelect?:(item:T)=>void};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<OrgChart roots={teams} getKey={t=>t.id} getChildren={t=>t.children} getLabel={t=>t.name} renderNode={t=><TeamCard team={t}/>} />
```

### State, interaction và rendering

Diagram decorative connections, parallel accessible tree/list hierarchy và node buttons only if select callback. Narrow list fallback, pan/zoom optional with keyboard buttons no drag-only. Static no lazy resolver default; cycles/duplicate keys error safe, max node rendering budget explicit consumer optional. Pure data async consumer DataState. Theme connectors nontext contrast.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Tree optional composition. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- X03-AC01: Raw T renderer/callback identity; cycle guard avoids recursion hang.
- X03-AC02: Mobile list contains every label and relations, keyboard selection accessible.
- X03-AC03: Single node/empty roots/long names and zoom limits stable.
