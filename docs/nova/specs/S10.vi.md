# S10 — CopyButton / useClipboard / ScrollArea

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** directives. **Dùng cho:** Các directive khả dụng chuyển thành UI/hook nhỏ và CSS.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
declare function useClipboard():{copy:(text:string)=>Promise<boolean>;pending:boolean;errorMessage?:string};
type CopyButtonProps={text:string;label?:string};
type ScrollAreaProps={label?:string;children:ReactNode;maxHeight?:string};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<CopyButton text={fileUrl} label="Sao chép đường dẫn" />
```

### State, interaction và rendering

Clipboard only user gesture, no hover-copy side effect; permission failure shows safe status and text selectable fallback. Button name clear, success live polite, timeout cleaned. Scroll area native overflow first, keyboard focus only if content overflow & region meaningful; no scrollIntoView on every update. Desktop/mobile directives CSS media utility, href→C06, tooltip→C12. SSR pending false no navigator read.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; browser clipboard; Button/Tooltip. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S10-AC01: Clipboard denied resolves false safe message, no throw uncaught/copy on hover.
- S10-AC02: Click double pending one flight, unmount cleans status timer.
- S10-AC03: Scroll keyboard and touch works, no empty region tab stop, no SSR navigator.
