# X06 — ImageEditor

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P3. **Nguồn Angular:** components/image-editor@c421f687. **Dùng cho:** Crop/rotate/flip/resize local image qua optional adapter, trả Blob và edits typed.

**Non-goals:** Không crop server, không tự upload, không bịa browser encoder hỗ trợ mọi format.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ImageEdits={flip:boolean;rotate:0|90|180|270;crop:{x:number;y:number;width:number;height:number};resize:{width:number;height:number}|null;aspectRatio:number|null};
type ImageEditorProps={source:Blob;label:string;maxPixels:number;maxInputBytes:number;exportOptions:{format:'image/png'|'image/jpeg'|'image/webp';quality:number;jpegBackground?:string};edits:ImageEdits;onEditsChange:(edits:ImageEdits)=>void;adapter:{decode:(source:Blob,ctx:LoadContext & {maxPixels:number;maxInputBytes:number})=>Promise<{width:number;height:number;renderPreview:(canvas:HTMLCanvasElement,edits:ImageEdits,ctx:LoadContext)=>Promise<void>;dispose:()=>void}>;export:(source:Blob,edits:ImageEdits,options:{format:'image/png'|'image/jpeg'|'image/webp';quality:number;jpegBackground?:string;signal:AbortSignal})=>Promise<Blob>};onExport:(result:{blob:Blob;edits:ImageEdits})=>void;disabled?:boolean};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<ImageEditor source={avatarFile} label="Chỉnh ảnh đại diện" maxPixels={16000000} maxInputBytes={10*1024*1024} exportOptions={{format:'image/png',quality:1}} edits={edits} onEditsChange={setEdits} adapter={imageAdapter} onExport={savePreview} />
```

### State, interaction và rendering

Source c421 existing component; Nova optional boundary, not permission to use image tool for implementation. EXIF decoded once; transform order flip→rotate→crop oriented pixels→resize; crop whole pixels within oriented image min1x1, resize positive integer; aspect ratio constraint explicit. Undo/redo immutable history instance, bounded100 candidate; source change resets and disposes. Keyboard numeric crop controls/move/resize alternatives to canvas drag; zoom preview not export geometry. No backend storage/upload. Decode/export AbortSignal latest-wins, large maxPixels required to bound memory, format unsupported returns safe error/no silently wrong MIME. Transparency JPEG background explicit consumer extension; no confidential pixel logging. SSR renders loading placeholder after mount, no canvas work. Decoder nhận budget từ trước allocation: kiểm tra Blob.size<=maxInputBytes, metadata dimensions pixel multiplication an toàn trước full raster decode; định dạng không thể preflight an toàn trả unsupported/budget error, không âm thầm decode để đo. Dimension thay bởi EXIF vẫn giữ pixel count. Adapter renderPreview vào canvas theo decoded resource, cleanup dispose resource. exportOptions format/quality finite0..1; JPEG source alpha cần jpegBackground explicit validated color (#RRGGBB), nếu thiếu chặn export với hướng dẫn, không default mất transparency. Export options changed invalidates pending export generation.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; optional image adapter/browser canvas with decode budget, Field/Button. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- X06-AC01: EXIF+flip90 rotation crop coordinate replay correct, corner boundaries and 1x1 valid.
- X06-AC02: Invalid crop/resize or maxPixels exceeded blocks export, no negative/NaN geometry.
- X06-AC03: Keyboard crop alternatives, source switch/unmount dispose/object URLs cleanup, no late onExport; format and alpha explicit.
- X06-AC04: Oversized metadata bị reject trước full raster allocation; adapter nhận budget; JPEG alpha thiếu background blocks, explicit background đúng pixel/MIME và quality boundary0/1.
