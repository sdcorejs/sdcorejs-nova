# S07 — useUnsavedChanges / Navigation adapter

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** services/unsaved-changes. **Dùng cho:** Bảo vệ draft trước navigation với registry scoped provider và explicit save/discard.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type UnsavedOptions={id:string;scopeKey:string;dirty:boolean;save?:()=>Promise<void>;discard?:()=>void|Promise<void>};
declare function useUnsavedChanges(options:UnsavedOptions):void;
declare function useConfirmLeave():(scopeKey?:string)=>Promise<'leave'|'stay'>;
type UnsavedChangesProviderProps={children:ReactNode;confirm:(options:{scopeKey?:string;entries:readonly {id:string;canSave:boolean}[]})=>Promise<'save'|'discard'|'stay'>};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
useUnsavedChanges({id:'profile',scopeKey:account.id,dirty,save:saveProfile,discard:resetProfile});
if(await confirmLeave(account.id)==='leave') router.push('/');
```

### State, interaction và rendering

No mandatory React Router/Next interception patches. Router adapter consumer calls confirmLeave before app nav; beforeunload only when dirty, browser controls generic text, no promise guarantee for mobile tab kill. Choices Save/Discard/Stay; failed save stays, no mark pristine unless app dirty prop becomes false. Multiple dirty entries scoped, prompts coalesce per scope, writes serialize; unmount unregister and listener clean. No auto persistence of sensitive drafts. Public UnsavedChangesProvider wraps app/router boundary, confirm adapter dùng Dialog (3 actions), không lấy binary ConfirmResult làm Save/Discard/Stay. Hook thiếu provider throws clear configuration error ngay hook use. SSR registration effect không run, không beforeunload module import; two provider roots independent.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Confirm/Dialog; router optional consumer adapter. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S07-AC01: Clean no prompt; dirty failed Save stay and draft intact.
- S07-AC02: Two nav requests same scope single prompt, Discard callback once each entry.
- S07-AC03: Provider root cleanup/unregister removes beforeunload; different scopes isolated; dirty=false during prompt reconciles leave decision safely.
