# D01 — DataTable / TablePagination

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/table. **Dùng cho:** Trình bày raw typed rows, sort/filter/page/selection, consumer actions và mobile renderer.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type PageState={pageIndex:number;pageSize:number};
type Sort={columnId:string;direction:'asc'|'desc'};
type Column<T>={id:string;header:ReactNode;cell:(row:T)=>ReactNode;sortKey?:string;minWidth?:number};
type TableState<K extends Key>={page:PageState;sort:readonly Sort[];selectedKeys:readonly K[]};
type DataTableProps<T,K extends Key>={rows:readonly T[];getRowKey:(row:T)=>K;columns:readonly Column<T>[];state:TableState<K>;onStateChange:(state:TableState<K>)=>void;total?:number;hasNextPage?:boolean;isRowSelectable?:(row:T)=>boolean;expandedKeys?:readonly K[];onExpandedKeysChange?:(keys:readonly K[])=>void;slots?:{title?:ReactNode;footer?:ReactNode;quickSearchRight?:ReactNode;group?:(rows:readonly T[])=>ReactNode;filter?:ReactNode;commandHeader?:ReactNode};loading?:boolean;errorMessage?:string;onRetry?:()=>void;rowActions?:readonly MenuAction<T>[];renderMobileRow?:(row:T)=>ReactNode;renderExpanded?:(row:T)=>ReactNode;caption:string};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<DataTable rows={page.items} columns={columns} getRowKey={r=>r.id} state={state} onStateChange={setState} total={page.total} loading={pending} caption="Danh sách tệp" rowActions={fileActions} renderMobileRow={file=><FileCard file={file}/>} />
```

### State, interaction và rendering

Table is controlled server/client headless surface, no fetch in component. state callback one atomic update, pageIndex reset on sort/filter only orchestrator chosen. Semantic table with caption, sortable header button aria-sort; no spreadsheet grid role unless editable grid separate spec. Selection keys stable, header selects current loaded eligible page only, all dataset explicit consumer action. Row/cell/footer/title/group/expanded/quickSearchRight directives map render slots, not Angular template registry. Expansion separate controlled keys extension, no nested recursive table default. Client sorting opt-in helper separate, server pass-through unchanged. Empty rows, initial skeleton, refresh keep rows, error region with retry, total unknown no fabricated last page. Mobile renderer optional else horizontal scroll labelled area; content not hidden silently. Virtualization opt-in after keyboard/SR proof; no requirement default. Unknown total bắt buộc hasNextPage, default false nếu thiếu và dev diagnostic; expansion chỉ enabled khi có expandedKeys+callback+renderExpanded đầy đủ, không tự uncontrolled key store. Slots nằm API kể trên; filter schema/loading/request orchestration nằm consumer. Trường state.page luôn kiểm tra pageSize integer>0 và pageIndex integer>=0.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; TanStack Table internal candidate; Button/Field/DataState/Pagination. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- D01-AC01: Slow request after filter change never owned by table; consumer orchestration fixture verifies latest rows.
- D01-AC02: Raw T at cell/action/mobile slots; row keys 0/string0 distinct, duplicate diagnostic.
- D01-AC03: Page selection disabled rows skipped, selected key missing retained until consumer changes; no select-all server illusion.
- D01-AC04: Unknown total Next enabled by explicit hasNext extension; 0 total correct disabled nav, pageSize>0, invalid negative reject.
- D01-AC05: Sort/selection keyboard semantics, mobile content parity, expansion focus, root Button import does not bundle TanStack.
