# S04 — ConfirmProvider / useConfirm

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** services/confirm. **Dùng cho:** Imperative confirmation từ event handler scoped provider; cancel rõ ràng.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ConfirmOptions={title:string;description?:string;confirmLabel?:string;cancelLabel?:string;tone?:'neutral'|'danger';signal?:AbortSignal};
type ConfirmResult='confirmed'|'cancelled';
declare function useConfirm():(options:ConfirmOptions)=>Promise<ConfirmResult>;

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
const result=await confirm({title:'Xóa tệp?',tone:'danger'});
if(result==='confirmed') await deleteFile(file.id);
```

### State, interaction và rendering

UI asks decision only, không chạy destructive callback. FIFO queue root; same event token optional dedupe separate explicit request ID, no title-based dedupe. Initial focus Cancel for danger. Escape/outside → cancelled, confirm explicit button → confirmed; signal aborted/provider unmount settle cancelled once, remove queued request. Missing provider throws clear dev/config error at hook use; SSR invocation unsupported event API returns cancelled safe and diagnostic, never pending forever. No HTML string.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI AlertDialog. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S04-AC01: Confirm returns confirmed only explicit click; Escape returns cancelled.
- S04-AC02: Two concurrent FIFO, abort queued never shown, unmount settles all once.
- S04-AC03: Danger default focus Cancel, Vietnamese long title/description readable mobile, focus return invoker.
