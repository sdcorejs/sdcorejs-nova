# S05 — useAsyncAction / BusyBoundary

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** services/loading. **Dùng cho:** Pending state và explicit async action singleflight cho user task.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
declare function useAsyncAction<A extends readonly unknown[],R>(action:(ctx:LoadContext,...args:A)=>Promise<R>):{run:(...args:A)=>Promise<R>;pending:boolean;error:unknown;cancel:()=>void};
type BusyBoundaryProps={busy:boolean;label:string;children:ReactNode;mode?:'indicator'|'block'};
declare class ActionInProgressError extends Error { readonly code: "ACTION_IN_PROGRESS" }

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
const save=useAsyncAction(async({signal},values:Profile)=>saveProfile(values,signal));
<Button loading={save.pending} onClick={()=>{void save.run(profile).catch(showSaveError)}}>Lưu</Button>
```

### State, interaction và rendering

Duplicate run while pending rejects ActionInProgressError, including arguments khác; không silently trả promise của invocation trước; scoped hook no global overlay refcount unless composed BusyBoundary. mode indicator keeps content, block aria-busy and explicit disables actions via consumer, never invisible pointer overlay trap. cancel AbortSignal ignores late result state but returns promise rejection AbortError; doesn't rollback backend. error raw only consumer, no automatic toast. Unmount cleanup, StrictMode effects not auto-run action. run wraps action with abort race: cancel/unmount settles caller promise AbortError ngay cả khi adapter bỏ qua signal, late adapter rejection được consume không unhandled. Consumer phải catch error hoặc truyền mapped UI error; cancel local không chứng minh remote cancellation.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Spinner/DataState. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S05-AC01: Hai run đồng thời, cả arguments giống/khác: invocation thứ hai rejects typed ActionInProgressError và adapter chỉ gọi lần đầu; pending reset thành công/lỗi.
- S05-AC02: Cancel/unmount abort and no post-unmount state/focus; retry run new attempt.
- S05-AC03: Two hooks pending independent; SSR hook pending false and no action until event.
- S05-AC04: Adapter bỏ qua abort vẫn caller AbortError ngay, late rejection không unhandled và không thay state của run mới.
