# F16 — SegmentedControl

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/segmented@c421f687. **Dùng cho:** Nhóm lựa chọn compact cho single hoặc multiple values.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type SegmentValue=string|number|boolean;
type SegmentOption<V extends SegmentValue>={value:V;label:string;icon?:ReactNode;disabled?:boolean};
type SegmentedProps<V extends SegmentValue> = ControlProps & {items:readonly SegmentOption<V>[];variant?:'light'|'fill'|'outline';orientation?:'horizontal'|'vertical';stretch?:boolean} & ({multiple?:false;value:V|null;onValueChange:(value:V|null)=>void;allowEmpty?:boolean}|{multiple:true;value:readonly V[];onValueChange:(values:readonly V[])=>void;allowEmpty?:never});

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<SegmentedControl label="Kiểu hiển thị" items={[{value:'list',label:'Danh sách'},{value:'grid',label:'Lưới'}]} value={view} onValueChange={setView} />
```

### State, interaction và rendering

Single radio group semantics, multi toggle group aria-pressed; user choice not tabs (no tabpanel). Default allowEmpty=false, repeat click single doesn't clear; true cho phép nút Bỏ chọn emit null. Multi emits fresh array in items order. Icons decorative and explicit label always supplies accessible names. Arrow roving + Space/Enter select, disabled skip, narrow wrap or vertical recommended no truncated icons-only unexplained. No async loader built-in; consumer immutable items. Boolean false value distinct empty; explicit controlled-only collection proposal (uncontrolled via wrapper app state if needed, not all controls must implement both). Single arrows chọn ngay theo native radio (và move focus), horizontal RTL trái/phải đảo logical direction; vertical Up/Down chọn trước/sau. Multi arrows chỉ focus, Space/Enter toggle. allowEmpty=true bổ sung explicit nút Bỏ chọn cạnh group, repeat-click active single không đổi semantics radio; nút Clear emits null, không required radio group. Custom renderer không giấu Clear alternative.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI ToggleGroup/RadioGroup reviewed chosen implementation. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F16-AC01: 0/false keys valid, duplicates type+value diagnostic.
- F16-AC02: Single repeat click active không clear; allowEmpty=true explicit Bỏ chọn emits null; arrows native single select immediately, multi arrows only focus and Space toggle ordered array.
- F16-AC03: Keyboard RTL/orientation and contrast for all variants; no tabs role because no panels.
