# F03 — NumberInput

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/input-number. **Dùng cho:** Giá trị numeric có draft text, min/max/step locale.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type NumberInputProps = ValueProps<number|null> & ControlProps & { min?:number;max?:number;step?:number; locale?:string; onDraftChange?:(text:string)=>void };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<NumberInput label="Số lượng" value={quantity} onValueChange={setQuantity} min={0} step={1} />
```

### State, interaction và rendering

Draft '-'/'1,' tồn tại khi gõ, chỉ emit finite parsed number lúc valid/commit; empty emit null. Không convert tiền sang float silently; currency exact precision consumer string adapter. Arrow step, disabled buttons at bounds, wheel không đổi khi chỉ scroll page. Invalid commit giữ draft+error và value cuối valid, blur không clamp bí mật. Locale parser separator ambiguous rejected with message.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI NumberField. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F03-AC01: 0 valid, empty null, NaN/Infinity không emit.
- F03-AC02: min=max, step fractional precision stable; min>max invalid config.
- F03-AC03: Negative draft, pasted vi 1.234,5, caret và keyboard arrows giữ semantics.
