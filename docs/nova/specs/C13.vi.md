# C13 — ResizableDialog / Splitter

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/modal-resizable,components/splitter. **Dùng cho:** Điều chỉnh kích thước panel bằng pointer và bàn phím.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type SplitterProps = ValueProps<readonly number[]> & { orientation?: 'horizontal'|'vertical'; minSizes?: readonly number[]; children: ReactNode };
type ResizableDialogProps = DialogProps & { size?: {width:number;height:number}; onSizeChange?: (size:{width:number;height:number})=>void };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Splitter defaultValue={[35,65]} minSizes={[20,20]}><FileList /><Preview /></Splitter>
```

### State, interaction và rendering

Size phần trăm cho splitter sum=100, min constraints validated; keyboard separator arrows +/-1%, Shift +/-10%, Home/End min/max, aria-valuenow; pointer capture cleanup. Dialog resize keyboard handle accessible; narrow không resize, full sheet. Persist consumer opt-in, no default localStorage. Window resize clamp viewport; no infinite ResizeObserver feedback.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; browser pointer/resize APIs. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C13-AC01: Drag vượt min clamp; invalid length/sum dev diagnostic và normalize safe.
- C13-AC02: Keyboard separator update percent, vertical up/down; disabled resize no change.
- C13-AC03: 320px no offscreen dialog; unmount during drag releases listeners/capture.
