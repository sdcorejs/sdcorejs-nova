# D04 — Tree / TreeItem

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/tree. **Dùng cho:** Hierarchy raw T, stable keys và lazy children một mức mỗi callback.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type TreeSource<T,K extends Key> = {mode:'static';roots:readonly T[];getChildren:(item:T)=>readonly T[]} | {mode:'lazy';roots:readonly T[];hasChildren:(item:T)=>boolean;loadChildren:(item:T,ctx:LoadContext)=>Promise<readonly T[]>};
type TreeProps<T,K extends Key>={scopeKey:string;source:TreeSource<T,K>;getKey:(item:T)=>K;getLabel:(item:T)=>string;expandedKeys:readonly K[];onExpandedKeysChange:(keys:readonly K[])=>void;selectedKeys?:readonly K[];onSelectedKeysChange?:(keys:readonly K[])=>void;actions?:readonly MenuAction<T>[];renderItem?:(item:T)=>ReactNode};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Tree scopeKey={account.id} source={{mode:'lazy',roots,hasChildren:n=>n.hasChildren,loadChildren}} getKey={n=>n.id} getLabel={n=>n.name} expandedKeys={expanded} onExpandedKeysChange={setExpanded} />
```

### State, interaction và rendering

Raw data proposal consciously differs Angular wrapper {id,label,data}; accessors preserve caller schema. Lazy callback one direct child level, core owns presentation expansion cache per instance/scope; consumer can supply externally controlled cache via optional adapter. Collapse cancels in-flight read; re-expand retry, branch error inline not whole tree. Known leaf never load. aria tree/treeitem/group, level/posinset/setsize for loaded siblings; arrows right expand/child, left collapse/parent, up/down visible nodes, Home/End. Independent selection default, no claiming unloaded descendants selected. Cycles/duplicate keys safe diagnostic; maxDepth consumer config and accessible truncation.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Button/ActionMenu/DataState. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- D04-AC01: Lazy callback returns direct children raw identity; no automatic deep recursion fetch.
- D04-AC02: Double expand single read; collapse/unmount/scope swap abort and late response ignored.
- D04-AC03: Keyboard parent/child focus, loading and retry accessible, static cycle rejected, zero root empty.
