# C12 — Popover / Tooltip

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** directives,components/anchor. **Dùng cho:** Nội dung anchored nhỏ và giải thích hover/focus.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type PopoverProps = ValueProps<boolean> & { trigger: ReactNode; children: ReactNode; placement?: 'top'|'bottom'|'start'|'end'; label: string };
type TooltipProps = { content: string; children: ReactNode; delayMs?: number };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Tooltip content="Sao chép đường dẫn"><IconButton label="Sao chép đường dẫn" icon={<CopyIcon />} /></Tooltip>
```

### State, interaction và rendering

Tooltip focus/hover, Escape dismiss, noninteractive text; touch long press không bắt buộc, name của trigger vẫn đủ. Popover interactive focus quản lý theo content, không trap nếu nonmodal; outside click và anchor scroll reposition. Không dùng Tooltip chứa button. Portal clipping/flip; overlay inherit tokens. Empty tooltip không render, disabled trigger cần wrapper focus policy explicit. Tooltip hoverable/persistent: pointer vào vùng tooltip không dismiss; không autoclose theo timer khi trigger/tooltip hovered hoặc trigger focused, chỉ Escape hoặc hover+focus exit. No interactive content vẫn cho pointer traverse gap qua safe area. Touch information luôn có accessible trigger label, essential help xuất hiện inline description, không yêu cầu long press.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Popover/Tooltip. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C12-AC01: Tooltip không thay aria-label và không nhận focusable children content.
- C12-AC02: Anchor sát mép 320px flip/clamp, scroll không detached popup.
- C12-AC03: Timer cleared unmount; Escape dismiss giữ trigger focus; no document SSR.
- C12-AC04: Pointer trigger→tooltip không mất content; focused lâu không timeout; Escape dismiss đến khi hover/focus transition mới; essential touch help inline.
