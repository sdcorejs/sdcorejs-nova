# F14 — useFormValidation / RHF adapter

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/models,forms/directives. **Dùng cho:** Validation engine-free function và optional adapter cho form library.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ValidationIssue<K extends string> = {field:K;message:string;code:string};
type Validator<T> = (values:T,ctx:LoadContext)=>readonly ValidationIssue<Extract<keyof T,string>>[]|Promise<readonly ValidationIssue<Extract<keyof T,string>>[]>;
declare function useFormValidation<T>(options:{validate:Validator<T>}):{ validate:(values:T)=>Promise<readonly ValidationIssue<Extract<keyof T,string>>[]>;pending:boolean;reset:()=>void };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
const validation = useFormValidation<Profile>({validate: validateProfile});
const issues = await validation.validate(values);
```

### State, interaction và rendering

Không phát minh reactive FormGroup mới. Pure sync validators composable và async hook latest-wins; touched/dirty thuộc consumer/RHF. submit validation request có immutable values snapshot, pending và cancel; external app save separate, no automatic API. RHF adapter maps value/ref/onBlur/errors theo controller, does not bundle RHF. Validators return typed issues, no HTML strings; reject maps safe general issue via consumer callback.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; optional React Hook Form peer adapter. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F14-AC01: Async email A/B resolves latest only; reset abort clears issues.
- F14-AC02: Required null/empty vs 0/false distinct; exact min/max boundaries.
- F14-AC03: Adapter ref focus first invalid, blur touched, disabled and native form submission match controls.
