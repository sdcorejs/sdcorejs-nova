# F09 — DatePicker / DateRangePicker / Calendar

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/date,forms/date-range. **Dùng cho:** Ngày lịch không timezone, date range cho lịch hoặc lọc.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ISODate = string; // runtime YYYY-MM-DD hợp lệ
type DatePickerProps = ValueProps<ISODate|null> & ControlProps & { min?:ISODate;max?:ISODate;isDateDisabled?:(date:ISODate)=>boolean };
type DateRange = {start:ISODate|null;end:ISODate|null};
type DateRangePickerProps = ValueProps<DateRange> & ControlProps & { min?:ISODate;max?:ISODate };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<DateRangePicker label="Khoảng ngày" value={range} onValueChange={setRange} min="2026-01-01" />
```

### State, interaction và rendering

ISODate không parse Date(local midnight). Typed text locale vi dd/MM/yyyy và popup calendar; arrows ngày, PageUp/Down tháng, Home/End tuần, Enter select, Escape restore focus. Range partial emitted explicit nulls; end<start rejected with error, không đảo silently. Date disabled cả typing và picker; mobile one month. Loading async N/A calendar; consumer blocked dates loading disables selection/status.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; calendar adapter source/license to verify at adoption. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F09-AC01: Leap 2024-02-29 valid, 2026-02-29 invalid, month end paging correct.
- F09-AC02: Min=max, end before start, partial range và null reset predictable.
- F09-AC03: SSR timezone UTC vs browser Asia/Ho_Chi_Minh render same date; grid labels full date.
