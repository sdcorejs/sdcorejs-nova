# C14 — AppShell / Sidebar / Navigation

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** modules/layout. **Dùng cho:** Shell trung lập cho end user: header/sidebar/main và navigation consumer-defined.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type NavItem = { id:string; label:string; href?:string; children?: readonly {id:string;label:string;href:string}[] };
type AppShellProps = { header?:ReactNode; sidebar?:ReactNode; children:ReactNode };
type SidebarProps = ValueProps<boolean> & { label:string; children:ReactNode };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<AppShell header={<AccountHeader />} sidebar={<Navigation items={links} currentId="files" />}>{page}</AppShell>
```

### State, interaction và rendering

Không default tenant switching/auth/permission menus. Consumer filter links; UI không security boundary. Desktop sidebar collapse controlled, mobile trigger opens modal drawer with focus. Skip-to-content anchor, nav landmarks distinct labels; active aria-current, one-level nav children. CSS breakpoints not hydration JS branch. LayoutStorage/MenuUtils chỉ capability responsive/shell, không Angular NavigationState store.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Dialog, Button, Breadcrumb. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C14-AC01: Skip link đưa focus main.
- C14-AC02: Sidebar mobile closes focus trigger, desktop collapse không xóa active page state.
- C14-AC03: No nav auth inference; deeper children reject; long Vietnamese menu 200% zoom scrolls.
