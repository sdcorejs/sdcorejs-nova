# C03 — Avatar / AvatarGroup

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** components/avatar. **Dùng cho:** Nhận diện người dùng bằng image hoặc initials, group overlap giới hạn visible.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type AvatarProps = { name: string; src?: string; alt?: string; size?: 'sm'|'md'|'lg'; decorative?: boolean };
type AvatarGroupProps = { children: ReactNode; label: string };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Avatar name="Nguyễn An" src={profile.avatarUrl} />
```

### State, interaction và rendering

Image failure chuyển initials deterministic theo Unicode grapheme, không hash random colors. Decorative có aria-hidden, meaningful image alt=name mặc định, tránh announce initials lặp. Empty name fallback icon + label localized. Không fetch profile; src change reset failure. Dark/light neutral, nhóm +N có text accessible.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Avatar. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C03-AC01: Ảnh lỗi chuyển NA và giữ kích thước.
- C03-AC02: Tên emoji/grapheme không cắt surrogate; empty name fallback đúng.
- C03-AC03: Decorative không đọc hai lần; SSR và client cùng initials.
