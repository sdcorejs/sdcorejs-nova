# F06 — RadioGroup

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** forms/radio. **Dùng cho:** Chọn đúng một lựa chọn trong nhóm.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type RadioGroupProps<K extends Key> = ValueProps<K|null> & ControlProps & { options:readonly {value:K;label:ReactNode;disabled?:boolean}[]; orientation?:'horizontal'|'vertical' };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<RadioGroup label="Kênh nhận tin" value={channel} onValueChange={setChannel} options={[{value:'email',label:'Email'},{value:'sms',label:'SMS'}]} />
```

### State, interaction và rendering

Fieldset/legend, roving focus arrow và Home/End nếu primitive support verified; checked single, disabled skipped. Selected missing option hiển thị no selection+warning, không tự emit null trong render. Empty options show localized empty read-only explanation; loading options consumer supplied skeleton outside. Mobile vertical preferred wrap; form name serializes key string explicit.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI RadioGroup. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F06-AC01: Arrow chuyển đúng option và emit once; disabled skip.
- F06-AC02: 0 key không xem empty; numeric/string keys không collision.
- F06-AC03: No options no fake radio; required null native/form adapter validation.
