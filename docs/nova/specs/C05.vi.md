# C05 — Card / CardGroup / Section

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** components/card,components/section. **Dùng cho:** Nhóm nội dung bằng heading, description, body và footer composable.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type CardProps = SurfaceProps & { children: ReactNode };
type SectionProps = { title: ReactNode; headingLevel?: 2|3|4; description?: ReactNode; actions?: ReactNode; children: ReactNode };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Section title="Thông tin hồ sơ" actions={<Button>Chỉnh sửa</Button>}><Card>...</Card></Section>
```

### State, interaction và rendering

Không biến card thành clickable root khi có interactive children. HeadingLevel explicit; SectionItem composable body, không schema-generated layout. Actions wrap dưới title ở narrow; CardGroup CSS grid responsive. Pure composition, consumer render data states bằng C10; không tự load. Dark/light border ít shadow. Section không có collapse; Angular collapsed/collapsible được định đoạt riêng C17, SectionItem là semantic body chunk. CardGroup API children+gap token, không business layout engine.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C05-AC01: HeadingLevel render semantic h2/h3/h4.
- C05-AC02: 320px title+actions không chồng; 200% zoom vẫn đọc.
- C05-AC03: Tab chỉ vào actual interactive children, không card container.
