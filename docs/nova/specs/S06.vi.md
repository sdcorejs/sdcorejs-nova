# S06 — useTask / TaskProvider / JobProgress

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** services/task,components/job-progress. **Dùng cho:** Theo dõi long running job qua poll hoặc consumer stream adapter.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type TaskStatus='idle'|'queued'|'running'|'succeeded'|'failed'|'cancelled';
type TaskState<T>={id:string;status:TaskStatus;progress?:number;result?:T;message?:string};
type TaskSource<T>={mode:'poll';load:(ctx:{id:string;signal:AbortSignal})=>Promise<TaskState<T>>;intervalMs?:number}|{mode:'stream';subscribe:(id:string,onState:(state:TaskState<T>)=>void,onError:(error:unknown)=>void)=>()=>void};
declare function useTask<T>(options:{id:string;scopeKey:string;source:TaskSource<T>;initialState?:TaskState<T>;cancel?:(id:string)=>Promise<boolean>}):{state:TaskState<T>;connection:'idle'|'open'|'reconnecting'|'error';retry:()=>void;cancel:()=>Promise<boolean>};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
const task=useTask({id:jobId,scopeKey:account.id,source:{mode:'poll',load:loadJob,intervalMs:2000},cancel:cancelJob});
```

### State, interaction và rendering

Core not create jobs or manage auth URL. Poll minimum 1000ms candidate configurable upper, no overlap, pause hidden default recommendation, terminal stops; read retry max3 exponential backoff jitter capped30s recommended configurable. Stream unsubscribe cleanup, callback late ignored; explicit source adapter handles SSE auth/connect. Sharing only inside explicit TaskProvider same scopeKey+id+source identity; never module singleton. Cancel remote false remains running, local abort not terminal cancelled; terminal server state wins, impossible regressions ignored/diagnostic. Progress clamp finite; failure safe message, retry read connection not resubmit business job.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; optional scoped external store/useSyncExternalStore; Progress. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S06-AC01: Poll delayed>interval no overlap; terminal stops timers.
- S06-AC02: Same job ID different scope never share; source change cancels old response.
- S06-AC03: Cancel remote false/error does not mark cancelled; final success racing cancel reconciles server.
- S06-AC04: Stream unsubscribe once after last subscriber/unmount, stale event ignored, StrictMode mount/unmount no duplicate retained streams.
