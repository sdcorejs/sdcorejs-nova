# D02 — QueryBar / FilterPanel / OperatorSelect

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/query-bar,components/operator. **Dùng cho:** Filter nhanh typed, draft/apply/clear và operator phù hợp field kind.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type FilterValue=string|number|boolean|null|readonly Key[];
type FilterField={id:string;label:string;kind:'text'|'number'|'boolean'|'date'|'choice';operators:readonly string[]};
type FilterRule={fieldId:string;operator:string;value:FilterValue};
type QueryBarProps={fields:readonly FilterField[];value:readonly FilterRule[];onValueChange:(rules:readonly FilterRule[])=>void;onApply?:(rules:readonly FilterRule[])=>void;disabled?:boolean};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<QueryBar fields={fields} value={filters} onValueChange={setFilters} onApply={applyFilters} />
```

### State, interaction và rendering

Draft does not load on every keystroke by default; Apply emits validated canonical rules, Clear emits [] explicit. OperatorSelect private composition unless second use needs public; unsupported operators excluded by type metadata, no SQL serializer. Chip remove accessible, mobile filter sheet maintains draft through opening. Field dependent values not silently reset outside validation; errors inline. SSR no URL/localStorage read, consumer maps query params.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; input/select/date primitives. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- D02-AC01: Unknown field/operator cannot apply; number 0/boolean false preserved.
- D02-AC02: Clear once [] then consumer reset page; no duplicate onApply during pending.
- D02-AC03: Mobile reopen preserves draft; filter removals announce label and focus next.
