# F01 — Field / Label / FormErrors

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** forms/label,forms/directives,forms/models. **Dùng cho:** Kết nối label/description/error tới control native và grouped fields.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type FieldRootProps = { id?:string; label:ReactNode; description?:ReactNode; error?:ReactNode; required?:boolean; children:ReactNode };
type FormErrorsProps = { errors:readonly {id:string;message:string;fieldId?:string}[] };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Field label="Email" error={errors.email}><Input nameFromField name="email" value={email} onValueChange={setEmail} /></Field>
```

### State, interaction và rendering

Field ctx chỉ IDs/validity, không global FormGroup imitation. Label htmlFor, required marker visual+SR đúng, no duplicate asterisk announce. Group checkbox/radio fieldset legend. FormErrors links focus target, errors after touched/submit policy owned form. Error summary dynamic polite; submit focus first invalid only once. SSR useId same.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Field/Fieldset. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F01-AC01: Click label focuses actual input; description/error ids merge.
- F01-AC02: Required small label inline at narrow and 200% zoom.
- F01-AC03: Submit invalid focuses field, change without submit không steal focus; two fields unique SSR IDs.
