# C06 — Breadcrumb / Link

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P0. **Nguồn Angular:** components/breadcrumb,directives. **Dùng cho:** Điều hướng có semantics và router-agnostic href.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type BreadcrumbItem = { id: string; label: string; href?: string };
type BreadcrumbProps = { items: readonly BreadcrumbItem[]; renderLink?: (item: BreadcrumbItem) => ReactNode; label?: string };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<Breadcrumb items={[{id:'home',label:'Trang chủ',href:'/'},{id:'files',label:'Tệp'}]} />
```

### State, interaction và rendering

nav aria-label và ol; cuối aria-current=page, không clickable khi không href. Long ancestor có ellipsis visual nhưng accessible full name; mobile collapse qua button menu không xóa context. Link href protocol allow http/https/mailto/tel/relative; javascript rejected. External target blank rel noopener noreferrer. renderLink phải semantic anchor; app owns router.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- C06-AC01: Current có aria-current và không href giả #.
- C06-AC02: javascript: không tạo navigation; external rel đúng.
- C06-AC03: Empty items không tạo nav vô nghĩa; RTL separators và overflow vẫn accessible.
