# S03 — ToastProvider / useToast

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** services/notify. **Dùng cho:** Thông báo transient scoped root với dismiss/update và action.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type ToastInput={id?:string;tone?:'info'|'success'|'warning'|'error';title:string;description?:string;durationMs?:number|null;action?:{label:string;onAction:()=>void|Promise<void>}};
declare function useToast():{show:(input:ToastInput)=>string;update:(id:string,input:Partial<ToastInput>)=>void;dismiss:(id:string)=>void};

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
toast.show({tone:'success',title:'Đã lưu hồ sơ'});
```

### State, interaction và rendering

Provider local store; no exported global toast singleton. visible max=5 recommendation FIFO queue, duplicate id updates rather than creates; title accessible text, critical error persistent duration null recommended not universal autoclose. Default success/info 5000ms, pause pointer/focus/document hidden, no surprising buffer 500ms from Angular. aria live polite by default, error assertive opt-in explicit extension. Action pending once, rejection surfaced safely and toast stays. Mobile bottom safe area avoiding app nav via offset token. SSR no timers or toasts auto mounted; dispose timers/listeners and pending actions ignore late.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Base UI Toast. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- S03-AC01: Same id update once/live announcement meaningful; timeout pauses focused toast.
- S03-AC02: 5 visible+6th queue deterministic, dismiss pumps next; duration null never timeout.
- S03-AC03: Two roots isolated, provider unmount no timer DOM leak, action double click once.
