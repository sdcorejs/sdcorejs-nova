# F08 — MultiSelect / ChipInput

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P1. **Nguồn Angular:** forms/chip. **Dùng cho:** Nhiều lựa chọn keys hoặc chip strings tự do.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type MultiSelectProps<T,K extends Key> = ValueProps<readonly K[]> & ControlProps & { options:readonly Option<T,K>[]; maxSelected?:number };
type ChipInputProps = ValueProps<readonly string[]> & ControlProps & { maxItems?:number; normalize?:(value:string)=>string; validate?:(value:string)=>string|undefined };

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<ChipInput label="Thẻ" value={tags} onValueChange={setTags} validate={tag=>tag.length>30?'Thẻ quá dài':undefined} />
```

### State, interaction và rendering

Free input Enter commit valid chip, composition Enter không commit; duplicates exact by normalized value rejected. Remove buttons named Xóa thẻ <label>, Backspace empty draft focuses last chip before deletion (không xóa bất ngờ). MultiSelect key array preserved order; disabled selected still visible no remove; maxSelected config consumer. Chips wrap, +N summary phải mở accessible full list, no data loss. Empty list legitimate.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; Combobox/Button. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- F08-AC01: IME Enter không add; duplicate/invalid chip emits no changed list và announces error.
- F08-AC02: At max no add, remove allows add again; selected 0 works.
- F08-AC03: Keyboard remove preserves input focus; disabled/readOnly không delete.
