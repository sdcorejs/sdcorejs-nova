# D03 — QueryBuilder / serializeQuery

Đọc [hợp đồng chung](../architecture-and-conventions.vi.md) trước; các types và G-* ở đó là normative inheritance của spec này.

**Trạng thái:** proposed r1, P2. **Nguồn Angular:** components/query-builder. **Dùng cho:** Nhóm AND/OR typed AST cho advanced filtering, backend adapter consumer-owned.

**Non-goals:** Không tải dữ liệu hay áp đặt nghiệp vụ ứng dụng.

### API TypeScript và ví dụ

Các đoạn dùng types chung ở hợp đồng nền. Đây là chữ ký đề xuất, chưa typecheck với implementation. Compound parts nêu trong behavior/index là export candidate cùng subpath, không cần lớp wrapper trung gian.

```tsx
type QueryNode = {kind:'rule';id:string;field:string;operator:string;operand:{kind:'literal';value:FilterValue}|{kind:'field';field:string}} | {kind:'group';id:string;logic:'and'|'or';children:readonly QueryNode[]};
type QueryBuilderProps = ValueProps<QueryNode|null> & { fields:readonly FilterField[];maxDepth?:number;maxRules?:number;allowFieldCompare?:boolean;readOnly?:boolean };
declare function serializeQuery(node:QueryNode|null):unknown;

// Ví dụ consumer; callback/data do ứng dụng cung cấp.
<QueryBuilder value={query} onValueChange={setQuery} fields={fields} maxDepth={4} maxRules={50} />
```

### State, interaction và rendering

IDs UI-only excluded serialization; field compare allowlist compatible kind/group consumer metadata, default literal-only. Validation before emit/Apply; invalid literal no lossy coercion. Nest group controls accessible with named actions move up/down alternative to drag. maxDepth/maxRules recommended defaults 4/50, configurable to avoid runaway UI, not business limit. Null empty query; group empty invalid until user resolves; serializer JSON AST, never eval expression/raw SQL. Collapse is UI local not emitted.

Áp dụng G-STATE, G-LIFECYCLE, G-A11Y, G-RENDER, G-I18N, G-COMPOSE ở mức phù hợp. Khi API không có value, UI chỉ presentational hoặc state local được mô tả ở trên; không thêm uncontrolled business state. Pure display không tự tạo loading/error callback. Mobile/light-dark/SSR theo hợp đồng nền và ngoại lệ trong behavior; async chỉ ở API có adapter/callback.

**Dependencies/composition:** React; QueryBar/Field/ActionMenu. Heavy adapters chỉ trong subpath riêng.

### Acceptance criteria và testcases

- D03-AC01: Serialize→parse roundtrip keeps semantic literal values no UI IDs.
- D03-AC02: Field compare disabled rejects crafted operand; string vs date rejected.
- D03-AC03: Depth/rule max boundary and cycles invalid input handled safe; delete focused group returns parent action.
