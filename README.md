# sdcorejs-nova

SD Nova là Core UI React độc lập cho trang end user, package đề xuất `@sdcorejs/nova`, tham khảo capability của `@sdcorejs/angular` và dùng shadcn/Base UI làm nền.

Repo hiện ở giai đoạn spec review, chưa chứa implementation hoặc package scaffold.

- [Bắt đầu đọc bộ spec Nova r1](docs/nova/README.md)
- [Mục lục tài liệu](docs/README.md)

Tài liệu có 59 spec, architecture/conventions candidate, inventory provenance và review độc lập. Các API là proposed; cần duyệt contract trước triển khai.
